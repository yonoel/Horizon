## [RFC 10008 推出 HTTP QUERY 方法，支持带请求体的安全幂等查询](https://www.rfc-editor.org/info/rfc10008/) ⭐️ 7.0/10

RFC 10008 定义了新的 HTTP QUERY 方法，允许通过请求体执行复杂数据查询，同时保持安全与幂等特性，解决了长期以来使用 GET 带请求体的问题。 这一标准化为 API 提供了一种清晰的方式处理复杂查询，避免了误用 GET 或 POST，改进了 HTTP 语义、缓存潜力及表单行为，对开发者和 Web 生态具有重要意义。 QUERY 方法是安全且幂等的，请求体可能用作缓存键，但这带来了缓存键大小无限制和需要位比较等挑战。IETF 出于历史互操作性问题拒绝了带请求体的 GET 方法。

hackernews · schappim · 6月17日 10:51 · [社区讨论](https://news.ycombinator.com/item?id=48568502)

**背景**: HTTP 传统上使用 GET 进行安全、幂等的无请求体检索，使用 POST 进行非幂等的带请求体提交。安全方法支持请求体这一缺失催生了 QUERY。RFC 编号是 IETF 发布的互联网标准文档的序列标识。
